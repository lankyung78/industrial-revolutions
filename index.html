    Editing and adding questions

    Open this file in a plain-text editor and find QUESTION BANK. Each question has an ID, era number, prompt, four choices, correct-answer index, and explanation. The correct-answer index is zero-based: 0 = A, 1 = B, 2 = C, 3 = D.

    To add a question, copy an existing question object inside the QUESTIONS array. Give it a unique ID and separate objects with commas. Use an era number from 1 to 4. Update the correct index whenever you reorder choices.

    Question count and scoring

    Find SETTINGS in the script below. questionLimit: null uses every question. Set it to a positive whole number, such as 12, to select a balanced random subset across available eras.

    The score is the percentage correct, rounded to a whole number. The default maximum is 100. Change maximumScore to use another scale. Wrong answers earn zero, with no penalty. Each default question is worth 5 points. Per-era percentages always show the percentage correct within that era.

    Launching and publishing

    Open this HTML file in a browser. It requires no installation, server, Internet connection, login, or external service. JavaScript must be enabled. Refreshing clears the attempt.

    To publish later, upload this file to a static web host. For faberludens.co.kr, place it in a separate /industrial-revolutions/ directory as index.html, then link to that page from your educational website. Confirm the hosting setup and obtain approval before changing the live site.

    It can also be embedded in an iframe with the quiz URL, a descriptive title, 100% width, and sufficient height. A direct link is often easier on phones. No deployment or live website modification has been performed.

    Accessibility and privacy

    Use Tab to move between controls and arrow keys to move within the answer group. Feedback is announced through a live region. Answers lock after submission. Reduced-motion preferences are respected. No personal information, cookies, analytics, or browser storage are used. Answers exist only in memory.

    This is a formative learning activity. Correct answers are visible in the source, so it is not a secure examination tool.

    Historical context

    The four-revolution framework is a teaching model with debated boundaries. Digital computers and networking began before the 1970s; that period emphasizes wider diffusion. AI also predates the twenty-first century; the fourth-revolution framework emphasizes connected, data-driven systems.

    Further reading: Encyclopaedia Britannica on the Industrial Revolution and James Watt; The Henry Ford on the moving assembly line; Taylor’s The Principles of Scientific Management (1911); Computer History Museum’s Timeline of Computer History; Internet Society’s A Brief History of the Internet; CERN’s history of the Web; and NIST publications on cyber-physical systems and AI risk management.
